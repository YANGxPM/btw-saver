# save (/btw:save)

The user just used `/btw` and wants to preserve the answer — or they want to
re-ask the same question and save the result permanently.

## Steps

1. **Read the argument**: everything after `/btw:save` is the question.
   If no argument is provided, ask the user: "What was your /btw question?"

2. **Answer the question** using the current conversation context — same as
   `/btw` would, but you may use tools if needed.

3. **Save to log file** using the Bash tool:
   - Log path: `.btw-log/btw-log.md` in the current project root
   - If `.btw-log/` does not exist → create it with `mkdir -p`
   - If `btw-log.md` does not exist → create it with this header:
     ```
     # /btw Log
     > Auto-generated by btw-saver. Answers to side questions you wanted to keep.

     ```
   - Append a new entry (use `date '+%Y-%m-%d %H:%M'` for timestamp):
     ```
     ---
     ## [2026-05-05 14:32] <question here>

     <answer here>

     ```

4. **Confirm**: show the answer inline and confirm the save path in one line:
   `Saved to .btw-log/btw-log.md`

## Rules

- Never truncate or summarize the answer when writing to the log.
- Never modify existing log entries.
- The log file is append-only.
